# 917 — Reverse Only Letters

## Problem

Two pointers: skip non-letters, swap letters only.

**Difficulty:** Easy | **Topic:** Strings

**[View on LeetCode](https://leetcode.com/problems/reverse-only-letters/)**

---

## Approach 1 — Two pointers ✅

**Idea:** Left and right pointers. Skip non-alpha characters. Swap letters when both pointers land on letters.

**Complexity:**
- Time: O(n)
- Space: O(n)

---

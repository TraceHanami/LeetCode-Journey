# 345 — Reverse Vowels of a String

## Problem

Two pointers: swap vowels only, skip consonants.

**Difficulty:** Easy | **Topic:** Strings

**[View on LeetCode](https://leetcode.com/problems/reverse-vowels-of-a-string/)**

---

## Approach 1 — Two pointers ✅

**Idea:** Left and right pointers skip non-vowels and swap vowels. Convert string to list first.

**Complexity:**
- Time: O(n)
- Space: O(n)

---

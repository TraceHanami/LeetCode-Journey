# 3612 — Process String with Special Operations II

## Problem

Efficiently simulate using a rope or deque to handle large multiplications.

**Difficulty:** Hard | **Topic:** Strings

**[View on LeetCode](https://leetcode.com/problems/process-string-with-special-operations-ii/)**

---

## Approach 1 — Modular simulation ✅

**Idea:** Track length with modular arithmetic to avoid building huge strings. Only compute final string at the end.

**Complexity:**
- Time: O(n)
- Space: O(n)

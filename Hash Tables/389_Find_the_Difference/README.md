# 389 — Find the Difference

## Problem
String t is generated by shuffling string s and adding one extra letter. Find that extra letter.

**Difficulty:** Easy | **Topic:** Hash Tables
**[View on LeetCode](https://leetcode.com/problems/find-the-difference/)**

**Examples:**
```text
Input: s = "abcd", t = "abcde"
Output: "e"
```

---

## My Approaches
### Attempt 1 — XOR All Characters ✅ Final Accepted Solution
**Why I used it:**
XORing every character of both strings together cancels all matching pairs, leaving only the extra character's code.

```python
def findTheDifference(self, s: str, t: str) -> str:
    r = 0
    for ch in s + t:
        r ^= ord(ch)
    return chr(r)
```

**Complexity:**
- Time: O(n)
- Space: O(1)

## Standard Approach
### Standard Approach 1 — Recommended ✅
### Idea
Because t is s plus one extra letter, XORing every character in both strings cancels every character that appears in both, leaving only the unmatched extra letter's ASCII code — the same trick as Single Number applied to characters.

```python
def findTheDifference(self, s: str, t: str) -> str:
    result = 0
    for ch in s + t:
        result ^= ord(ch)
    return chr(result)
```

### Complexity
- Time: O(n)
- Space: O(1)

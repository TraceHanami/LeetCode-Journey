# 389 — Find the Difference

## Problem

You are given two strings `s` and `t`. String `t` is generated by shuffling `s` and then adding one extra random character. Return the extra character added to `t`.

**Difficulty:** Easy | **Topic:** Hash Tables / Bit Manipulation

**[View on LeetCode](https://leetcode.com/problems/find-the-difference/)**

**Examples:**
```
s = "abcd", t = "abcde"  →  "e"
s = "",      t = "y"     →  "y"
```

---

## Approach 1 — XOR ✅

**Idea:** XOR all characters in both `s` and `t`. Every character in `s` has a matching character in `t`, so they cancel out. Only the extra character remains.

```python
class Solution1:
    def findTheDifference(self, s: str, t: str) -> str:
        result = 0
        for c in s + t:
            result ^= ord(c)
        return chr(result)
```

**Complexity:**
- Time: O(n)
- Space: O(1)

---

## Approach 2 — Counter Difference

**Idea:** Subtract frequency counts of `s` from `t`. The remaining key is the extra character.

```python
class Solution2:
    def findTheDifference(self, s: str, t: str) -> str:
        from collections import Counter
        diff = Counter(t) - Counter(s)
        return list(diff.keys())[0]
```

**Complexity:**
- Time: O(n)
- Space: O(1) — at most 26 keys

---

## Approach 3 — Sum of ASCII Values

**Idea:** The difference between the sum of ASCII values of `t` and `s` gives the ASCII value of the extra character.

```python
class Solution3:
    def findTheDifference(self, s: str, t: str) -> str:
        return chr(sum(ord(c) for c in t) - sum(ord(c) for c in s))
```

**Complexity:**
- Time: O(n)
- Space: O(1)

---

## Approach 4 — Sort and Compare

**Idea:** Sort both strings. Compare character by character — first mismatch is the extra character. If all match, the last character of `t` is the answer.

```python
class Solution4:
    def findTheDifference(self, s: str, t: str) -> str:
        s, t = sorted(s), sorted(t)
        for cs, ct in zip(s, t):
            if cs != ct:
                return ct
        return t[-1]
```

**Complexity:**
- Time: O(n log n)
- Space: O(n)
